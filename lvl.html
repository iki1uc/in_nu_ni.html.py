$ lvl — Repo Dashboard

lvl bei index.html: dieselbe Logik, ohne React-Bundle, ohne Server, ohne Limit. Alles lokal. 1 Datei = 1 Level. index.html bleibt wie sie ist — lvl liegt daneben, als eigene Schicht. Daten: localStorage lvl_repos + lvl_overrides.

Grün = aktiv · Gelb = offene Issues · Rot = >6 Monate inaktiv · Gold = ORI · Klick aufs Farbquadrat = Farbe manuell setzen (bleibt).

Repo hinzufügen / bearbeiten — All In

Taste / fokussiert die Suche. lvl ersetzt index.html nicht — es ist die saubere Schicht daneben. Wenn du willst, kopierst du lvl.html über index.html, oder lässt beide: index.html = beide Aufgaben, lvl.html = nur dieses Dashboard, schnell + lesbar.
